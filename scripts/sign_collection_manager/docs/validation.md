## 전처리 연동

기존 보안경 원영상으로 좌표 추출 JSON, 후처리 avatar JSON, 품질 보고서, 비교 영상을 생성했다. 기존 도구의 Python 3.12 환경과 관리 프로그램의 Python 3.11을 분리해 실행했다. 아바타 재생·수어 의미의 정확성을 검증했다는 뜻은 아니다.

실제 API 추천의 의미·수어 적합성 평가, 전문가 역할 인증, 사이트의 무인 수집, EAF/XML 전용 파서, 다중 사용자 운영은 검증·구현 범위에 포함하지 않았다.

## 검색 결과의 3D JSON 저장

선택한 원본 ID·글로스·시간 구간을 확인해 원본 3D 프레임만 내보낸다. 압축 보관본의 실제 조심1 구간에서 몸·얼굴·양손 3D 9프레임 내보내기를 확인했다. 방사선은 보유 자료에 글로스 시간이 있지만 해당 단어 구간의 좌표가 없어 다운로드가 차단되는 것을 확인했다. 3D 전용 검사에서 2D·평면 Z·다른 원본 ID·누락 구간을 거부하고, UI 검사에서 3D 및 2D 저장 버튼과 좌표 미보유 시 차단을 확인했다.

2D만 보유한 경우 원본 `x,y,confidence`를 보존해 `_2D.json`으로 제공한다. 모든 후보 출처의 3D를 우선 확인하며, 로컬에 2D가 먼저 있어도 압축 보관본에 3D가 있으면 3D를 선택한다. 실제 추가 압축 보관본의 2D 16프레임 내보내기를 확인했다.

대체 표현 화면에서 미분류 의미와 원문을 저장한 뒤 추천할 수 있다. 문맥 누락 시 API 요청 전에 안내하며, 동일 단어 중복 의미 충돌은 저장 전에 차단한다. 임시 DB·대역 API로 원문과 의미가 추천 요청에 전달되는 것을 확인했다.

영상 등록의 출처·이용조건은 선택 입력으로 제공한다. 공통 출처 설정은 DB에 저장해 다음 등록에도 재사용하고, 빈 값은 미확인으로 보존한다. 임시 영상·DB로 공통 설정 재사용과 입력 없이 등록되는 것을 확인했다.

전처리 결과 패널에서 후처리 JSON·보정용 영상/좌표 ZIP·비교 영상·검수 시간 구간을 제공한다. 시간표의 프레임 범위를 초 단위로 표시하며, 자동 검출 후보를 확정 오류로 간주하지 않는다. 얼굴 전체 누락도 별도 경고한다. 임시 결과 파일로 ZIP 내용과 화면 다운로드를 검사했다.

## 멘토 후처리와 양손 선형보간 결합

멘토 제공 원본 v3에도 선형보간이 포함되어 있다. 아래 검증은 보간 한도 분리와 관측값·출처 보존을 결합한 처리 결과다.

손 보간 한도를 몸·얼굴과 분리하고 기본 0.4초로 적용했다. 양손 각각의 앞뒤 관측점을 이용하며 0~1초로 조절 가능하다. 관측 좌표를 덮어쓰지 않고, 시작·끝·한도 초과 누락과 전 구간 미검출 손은 유지한다. 멘토 코드의 기존 처리 흐름은 작업별 엔진 복사본에서 사용한다.

실제 고열의 원본 추출 JSON을 재사용한 후처리 확인:

| 항목 | 기존 후처리의 남은 누락 | 양손 보간 후 남은 누락 |
|---|---:|---:|
| 왼손 | 16프레임 | 6프레임 |
| 오른손 | 7프레임 | 0프레임 |

처음 6프레임은 앞쪽 관측점이 없어 보간하지 않았다. 기존 유한 좌표 값이 그대로이며 추출 원본 해시가 같음을 확인했다. 가상 휴지 생성은 0프레임이고, 기존 전처리 프로그램의 모든 src 파일 해시도 유지됐다. 이 수치는 좌표 누락 감소이며 정답 대비 정확도나 수어 의미 복원 성과가 아니다. 얼굴 전체 누락과 실제 동작 검수는 별도로 남는다.

AI Hub 계열 좌표·재생상태 묶음 내보내기를 추가했다. 실제 고열의 149프레임·30fps 좌표와 상태가 일치하고 기존 로더로 읽히는 것을 확인했다. 원본 point_source·point_valid, 보간·수동·가상 자세 출처는 상세 상태에 보존한다. 기본 상태는 기존 로더의 0~3을 유지하고 미확인·가상 자세는 0으로 남긴다. 이 내보내기는 검수 승인이나 의미 검수를 자동으로 기록하지 않는다.

## 설치·실행 검증

- 별도 Python 3.11 가상환경에 requirements-dev.txt를 설치한 뒤 자동 테스트 60개를 통과했다.
- 프로젝트 외부 디렉터리에서 run.py를 실행해 HTTP health 응답을 확인했다.
- 단일 행·다중 행 make_check_video 분기 모두 보간 인자 연결을 확인했다.
- 기본 화면은 빈 DB에서 실행한다. 개인 DB·좌표·영상 없이 합성 입력으로 기능 검사를 수행한다.
- Windows 실행 명령과 Python 경로를 지원하지만 Windows 실기 검증은 수행하지 않았다. 외부 좌표 전처리 연동은 macOS/Linux 대상이다.

검증 패키지: Streamlit 1.67.0, NumPy 2.4.6, Pandas 2.3.3, Requests 2.34.2. 코드 형식은 Ruff 검사·포맷 검사를 통과했다.

## LLM 응답·문서 처리 검증

- JSON 응답 지시 누락에 따른 HTTP 400을 재현하고 요청 본문을 수정했다. API 오류 상세를 표시하되 키는 마스킹한다.
- 출력 한도에 도달한 응답을 완료 상태와 구분하고, 잘린 JSON을 성공 결과로 저장하지 않는다. 문서 핵심어는 JSON Schema로 필드·후보 수·발췌 길이를 제한한다.
- PDF 공백·줄바꿈 차이만 허용하고, 발췌문은 원문에서 직접 가져온다. 원문에 없는 후보는 제외하며 정상 후보까지 함께 버리지 않는다.
- 문서를 짧은 구간으로 나누고 진행률을 표시한다. 완료한 구간은 로컬에 보관하고, 재실행 시 재사용한다. 일부 구간이 실패해도 완료 결과를 반환한다.
- 길이 제한·형식 오류의 재분할 복구, 실패 구간만 재시도, 인증·한도 오류 시 남은 호출 중단, 손상된 재사용 파일 거부, macOS 파일명 정규화를 합성 응답으로 검사했다.
- 사용자 실행 화면에서 3페이지 발췌본의 3/3구간 완료와 핵심어 후보 28개 표시, 대체 표현 후보 3개 저장을 확인했다. 후보 개수는 정확도 지표가 아니며, 추천 표현에 대한 전문가 평가는 수행하지 않았다.
- 원본 PDF 25페이지 전체에 대한 유료 검증은 사용자 요청으로 중단했다. 전체 문서의 처리가 완료됐다고 보고하지 않는다.

이 수정본의 자동 테스트는 외부 HTTP 요청을 차단한 상태에서 실행한다. 실제 문서·API 응답·API 키·재사용 파일은 저장소에 포함하지 않는다.
