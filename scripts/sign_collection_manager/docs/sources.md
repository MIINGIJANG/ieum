확인일: 2026-11-24. 실제 HTTP 접근 상태는 `source_access.json`에 보관했다. 페이지 접근 가능성과 자동 수집·영상 재사용 허가는 서로 다른 문제다.

robots의 특정 봇 규칙은 프로그램 전체에 대한 허가나 금지를 자동으로 뜻하지 않는다. 공개 API와 자동 수집 허용 범위가 확인되지 않아 링크·수동 확인 방식으로 제공했다. 비공개 내부 요청을 공개 API로 포장하지 않는다.

## 영상 확보

이 프로그램은 사이트의 인증·접근 제한을 우회해 영상을 내려받지 않는다. 이용 조건을 확인해 확보한 영상 파일을 **데이터 관리 → 영상 보관**에서 선택하면 관리 폴더에 복사하고 해시로 중복을 차단한다. 검색 링크나 영상 URL을 저장했을 뿐이면 확보 완료로 표시하지 않는다.

정확 좌표 라벨, 사전의 표제어, 전문가가 검수한 번역은 각각 구별한다. 자동 추천만으로 수어 표현의 정확성을 확정하지 않는다.

## 코드 출처와 변경 범위

| 구성 요소 | 출처 | 변경·결합 범위 |
|---|---|---|
| `tools/postprocess_linear.py` | 프로젝트 멘토 제공 `postprocess_v3.py` | 내부 구간·좌표 성분별 보간, 양손 보간 한도 분리, 관측값 보존, 출처·검수 기록 |
| `ksl_manager/interpolation.py`, `preprocessing.py` | 본 프로젝트 | 작업별 엔진 구성, 전처리 연결, 추출 결과 재사용 |
| `avatar_conversion.py`, `tools/avatar_loader.py` | 이음 프로젝트의 전처리 모듈 | 변환 기능 분리, 좌표·재생상태 묶음 내보내기와 호환 확인 |
| 수집·검색·DB·추천·검수 화면 | 본 프로젝트 | 문맥별 자료 관리, 중복 확인, LLM 추천 연결, 검수·전달 현황 |

원본 v3에도 선형보간이 포함되어 있다. 본 프로젝트의 변경은 보간 조건과 한도, 관측·추정 좌표 구분 및 전체 처리 흐름에 대한 확장이다. 얼굴 관절 대응은 근사 매핑이며 깊이는 MediaPipe 모델의 상대 추정치다.

외부 제공 코드의 공개·재배포 허용 범위는 아직 확인되지 않았다. 출처 표기를 공개 허락으로 기록하거나 외부 제공 코드에 임의의 라이선스를 부여하지 않는다.
