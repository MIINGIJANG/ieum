# AI Hub 계열 구조 변환 결과

구현팀에는 AIHub_3D와 재생상태 폴더, 자료목록.json을 함께 전달합니다. 상대 3D 추정 자료이며 AIHub에서 수집한 원본 3D나 실측 정답으로 출처를 바꾸지 않습니다.

몸25·얼굴70·각 손21의 평탄 XYZ 배열입니다. 목·골반 중심은 평균으로, 얼굴70은 근사 선택으로 대응합니다. 원본에 없는 작은발가락과 얼굴468의 홍채 슬롯은 상태0입니다. 원본에 없던 관절을 관측된 점으로 만들지 않습니다.

avatar 입력은 기존 후처리 XYZ·FPS·프레임 수를 유지합니다. 관절 대응 이외에 새 보간, 깊이 추정, 크기 재조정, 손목 강제 정렬을 하지 않습니다. 보간 길이·가까운 깊이 설정은 raw 입력에만 적용됩니다.

재생상태의 point_status_codes를 반드시 읽습니다. 0=미확인, 1=모델 또는 이전 짧은 보간(구별 불가), 2=raw 변환 보간, 3=raw 최근접 깊이, 4=avatar 가상 휴지, 5=명시된 수동 좌표입니다. 가상 휴지와 미확인 점을 실제 검출로 계산하지 마세요. 원래 point_source·point_valid·합성 프레임과 손 휴지 가중치를 별도로 보존합니다.

AIHub_2D는 역투영 정보가 있는 avatar에만 생성합니다. XY는 원본 픽셀, 세 번째 값은 관측/모델 가용도 0/1로 깊이·정확도 점수가 아닙니다. 가상 휴지와 미확인 점은 0입니다.

JSON 형식 변환과 수어의 의미·3D 아바타 리타게팅 검증은 별도입니다.
