# 환각 방지: 근거가 없으면 답하지 않기

> 발표용 한 줄 요약: **"모르는 건 모른다고 답한다."** 문서에 근거가 약한 질문과 산업안전과 무관한 입력에는 답하지도, 수어로 바꾸지도 않도록 했다. 그 결과 문서 밖 입력 28개 중 28개를 거절(조치 전 0개)했고, 문서 안 질문 40개 중 38개에는 그대로 답한다.

## 1. 발견한 문제

| 입력 | 조치 전 화면 | 문제 |
|---|---|---|
| `안녕` | 답변: "복합식 디맨드형 안 면 부 에어라인마스크 압력디맨드형 안 면 부" / 수어: 작업·전·마스크·상태·확인 | 문서와 무관한 인사에 표 조각을 답으로 내고, 아무 관계 없는 수어까지 보여줌 |
| `안녕하세요` (문장으로 판단 → 번역) | 수어: 안전모·손상·즉시·교체 | 번역 모델이 아무 문장이나 학습한 안전 문장처럼 바꿈 |
| `보호구 교육은 몇 시간 받아야 하나요?` | 답변은 맞는데 수어: 근로자·떨어지다·위험·있다·작업·보호구·사용 | 답변을 번역 모델에 넣으면 답변에 없는 단어가 수어로 나옴 |
| `용접할 때 불꽃 튀면 뭘 착용해야 하나요?` | "작업할 때 안전모를 착용하세요" | 준비된 안내 문장과 글자가 조금만 비슷해도 그 문장으로 답함 |

수어 안내 서비스에서 틀린 안내는 답이 없는 것보다 위험하다. 사용자는 수어 화면만 보고 행동할 수 있기 때문이다.

## 2. 원인

1. **검색은 항상 무언가를 돌려준다.** TF-IDF 검색은 관련이 없어도 "그나마 가장 비슷한" 문단 3개를 반환한다. 추출식 답변은 그중 질문과 가장 비슷한 문장을 고르므로, 관련이 없어도 답이 만들어진다.
2. **번역 모델은 입력이 산업안전 문장인지 모른다.** 안전 문장으로만 학습해서 어떤 입력이든 안전 수어 단어로 출력한다.
3. **준비된 안내 문장 매칭이 글자 유사도만 봤다.** "작업", "착용"처럼 흔한 말이 겹치면 유사도 기준(0.45)을 넘었다.

## 3. 조치

| # | 조치 | 위치 |
|---|---|---|
| 1 | **검색 신뢰도 기준:** 검색 1위 점수가 0.11 미만이면 답하지 않음 | `ksl/pipeline.py` `min_score` |
| 2 | **번역 대상 제한:** 산업안전 핵심어(보호구·위험·작업·감전 등 60여 개)가 하나도 없는 문장은 번역하지 않음 | `data/kosha/domain_terms.txt`, `in_domain()` |
| 3 | **안내 문장 매칭 강화:** 유사도 기준에 더해, 안내 문장마다 정한 핵심어(예: 낙하물 → "낙하물", "물건이 떨어")가 질문에 있어야 함 | `data/kosha/answers.json` `keywords`, `_demo_ok()` |
| 4 | **답변 품질:** 기호만 나열된 표 조각은 답변 후보에서 제외. 화면 답변은 문서 근거로, 수어는 확정된 안내 문장으로 분리 | `ksl/rag.py`, `answers.json` |
| 5 | **수어 단어는 답변에서만:** 답변 문장에 실제로 있는 말만 수어 단어로 바꿈(단어표 `data/sign/sign_words.csv`). 학습이 덜 된 번역 모델이 답변을 엉뚱한 단어(예: 교육 시간 답변 → '근로자·떨어지다·위험')로 바꾸던 문제 제거. 동작이 있는 단어는 아바타가 표현하고, 없는 단어는 회색으로만 표시 | `ksl/pipeline.py` `SignWords`, `sign_sentence()` |

답하지 않을 때 화면은 다음과 같다.
- 답변: "개인보호구의 사용 및 관리에 관한 기술지원규정에서 관련 내용을 찾지 못했습니다."
- 수어 재생, 단어 목록, 출처는 표시하지 않는다. 아바타는 기본 자세를 유지한다.

### 기준값 0.11을 정한 근거

검색 1위 점수 분포를 비교했다.

| 질문 묶음 | 1위 점수 범위 |
|---|---|
| 문서 안 질문 dev 30개 | **0.117** ~ 0.308 |
| 문서 안 질문 held-out 10개 | 0.062 ~ 0.349 |
| 문서 밖 입력 22개 (인사·잡담·문서에 없는 안전 주제) | 0.043 ~ **0.105** |

dev 질문의 최저값(0.117)과 문서 밖 입력의 최고값(0.105) 사이인 0.11로 정했다.

## 4. 결과

`python scripts/eval/eval_abstain.py`로 재현할 수 있다.

| | 조치 전 | 조치 후 |
|---|---|---|
| 문서 안 질문 40개에 답함 | 40 (100%) | 38 (95%) |
| 그중 정답 쪽이 출처에 있음 (정답 쪽 표기된 38개 기준) | 33 | 32 |
| **문서 밖 입력 28개 거절** (인사·잡담 12, 문서에 없는 안전 주제 10, 무관한 문장 6) | **0 (0%)** | **28 (100%)** |
| 안전 안내 문장 10개 번역 | 10 | 10 |

대가로 문서 안 질문 2개(held-out)도 거절됐다.
- "배달 오토바이 탈 때 쓰는 헬멧 기준": 원래도 검색이 틀린 질문이다.
- "안전대 종류가 뭐가 있어요?": 검색은 맞았지만 점수가 0.062로 낮다.

신뢰도를 위해 일부 정답을 포기하는 정밀도 우선(precision-first) 선택이다.

## 5. 한계 (발표 때 함께 말할 것)

- **기준값과 평가 질문이 같은 세트다.** 0.11은 위 질문들을 보고 정했으므로 실제보다 좋게 보일 수 있다. 조원이 새로 만든 질문(문서 안·밖 각각)으로 다시 확인해야 한다.
- **문서 밖 질문 세트가 작고 직접 만든 것이다** (28개). 산업안전과 가까운 주제일수록 경계가 애매하다. 예: "소화기 사용법"의 점수 0.105는 기준과 거의 붙어 있다.
- **번역 모델 자체의 오류는 남아 있다.** 핵심어 검사는 "무관한 문장"만 막는다. 안전 문장 안에서 단어를 틀리게 바꾸는 오류(예: 안전모 → 안전대)는 번역 모델 학습 데이터가 늘어야 줄어든다. 그래서 검수된 5문장은 모델 대신 확정 글로스(번역 메모리)를 쓴다.
- **LLM 답변 모드(API 키가 있을 때)** 에도 같은 검색 기준이 먼저 적용된다. LLM에는 "문서에 없으면 '찾을 수 없습니다'라고 답하라"는 지시를 넣었다.

## 6. Claude 답변 모드를 켠 뒤 다시 평가 (2026-10-09)

검색된 문서 문단을 그대로 잘라 보여주던 방식(추출식) 대신, Claude(Haiku 4.5)가 **검색된 문단 안에서만** 짧고 쉬운 문장으로 답하게 했다. 거절 장치는 그대로 두고, 하나를 더했다.

- Claude 에게 "문서에 관련 내용이 없으면 '문서에서 찾을 수 없습니다'만 답하라"고 지시
- Claude 가 그렇게 답하면 화면은 **답하지 않음**으로 처리 (수어도 하지 않음) → 검색 점수 기준 다음의 **두 번째 거절 장치**

배포된 서버에서 같은 평가를 돌린 결과 (`/eval`, 코드: `ksl/evaluation.py`)

| | 추출식 (조치 후) | Claude 답변 모드 |
|---|---|---|
| 문서 안 질문 40개에 답함 | 38 (95%) | 36 (90%) |
| 정답 쪽이 출처에 있음 (정답 쪽 표기된 38개 기준) | 32 | 31 |
| **문서 밖 입력 28개 거절** | **28 (100%)** | **28 (100%)** |
| 안전 안내 문장 10개 번역 | 10 | 10 |
| 답변 길이 | 문서 문단 그대로 (길고 표 조각 섞임) | 1~2문장 (예: "정화통은 6개월마다 교체해야 합니다.") |

처음 평가에서 Claude 가 추가로 거절한 문서 안 질문 3개를 하나씩 확인했다 (그중 1개는 지시문을 고친 뒤 답함 → 위 표는 고친 뒤 결과).

| 질문 | 추출식이 보여준 답 | 판단 |
|---|---|---|
| 보호구 여러 개 같이 착용할 때 주의할 점 | "어떤 개인보호구를 선택할지는 … 고려하여 선택하여야 한다" (질문과 무관) | **Claude 거절이 맞음.** 정답 문단(23쪽 "서로 조화를 이루어야")이 검색 3위 안에 없었음 → 추출식은 엉뚱한 답(환각과 같은 효과) |
| 보호구 착용하는지 누가 확인해? | "근로자들의 건강 상태가 검사되어야 한다" (질문과 무관) | **Claude 거절이 맞음.** 문서에는 "정기적으로 검사"만 있고 '누가'는 없음 |
| 방진마스크 필터는 얼마나 준비해 둬야 해? | "사업주는 방진마스크의 필터 등을 … 충분한 양을 갖추어 두어야 한다" | **Claude 가 지나치게 엄격.** 숫자가 없어서 거절 → 지시문에 "딱 맞는 수치가 없어도 관련 규정이 있으면 문서 그대로 답하기"를 추가 → **다시 평가하니 답함** |

정리: 답한 비율은 2개 줄었지만, 그 2개 모두 추출식이 **질문과 무관한 문장을 답처럼 보여주던 경우**였다. Claude 모드는 "모르면 답하지 않는다"를 문장 단위까지 지킨다.

한계: Claude 답변은 실행할 때마다 표현이 조금씩 달라질 수 있고(같은 평가를 다시 돌리면 ±1~2개 차이 가능), 키가 없거나 호출이 실패하면 자동으로 추출식으로 돌아간다.
