# 첫 로딩과 오프라인

원칙: **쓰는 중에는 기다리게 하지 않는다.** 필요한 것은 첫 로딩 화면에서 모두 준비하고, 한 번 받은 것은 기기에 저장해
다음 방문과 인터넷이 없는 곳에서도 그대로 쓴다. 화면 모양·문구는 바뀌지 않는다.

- 화면: `web/index.html` (첫 로딩), `web/sw.js` (저장·오프라인)
- 서버: `ksl/webfiles.py` (미리 압축, 파일 목록), 엔드포인트 `/offline/manifest`

## 첫 로딩에서 준비하는 것

| 준비 | 내용 | 기다리는 한도 |
|---|---|---|
| 아바타 | 3D 모델 받기·옷 입히기 | 끝까지 |
| 카메라 수어 입력 | 낱말 인식 모델 + 관절 점 엔진(라이브러리·모델) 받기, 엔진 시작, 첫 계산 | 끝까지 |
| 서버 | 검색·동작 합치기를 미리 한 번 (`/warmup`) | 15초 |
| 예시 질문 | 목록, 화면에 보이는 예시의 답과 그 단어 동작 | 20초 |
| SOS | 카카오 지도 불러오기 (위치·응급실은 누를 때마다 새로) | 8초 |
| 글꼴 | IBM Plex Sans KR | 3초 |

로딩이 끝난 뒤에는 뒤에서: 나머지 예시 질문의 답·단어 동작, 출처 쪽 이미지, 오프라인용 나머지 파일.

### 빠르게 하려고 한 것

| 항목 | 예전 | 지금 |
|---|---|---|
| 카메라 준비 순서 | 단어 목록 → 인식 모델 → 엔진 라이브러리 → 몸 모델 → 손 모델 (차례로) | 인식 모델과 관절 점 엔진을 **동시에**, 그 안의 파일들도 동시에 받음 |
| 인식 모델 크기 | 26.1MB | 13.6MB (가중치를 16비트로 저장, 실행은 그대로 32비트 — `scripts/model/shrink_sign_model.py`) |
| 압축 | 요청마다 서버가 다시 압축 (큰 파일은 그만큼 느림) | 한 번 압축해 둔 파일을 그대로 보냄 (`ksl/webfiles.py`) |
| SOS 준비 | 위치를 허락한 기기는 응급실 조회까지 (쓰이지 않는 결과) | 지도만 |
| 두 번째 방문 | 큰 모델만 저장해 둔 것 사용, 나머지는 다시 받음 | 바뀌지 않은 파일은 모두 저장해 둔 것 사용 (요청 한 번으로 확인) |

## 저장 방식 (`web/sw.js`)

```
웹 파일 요청 → 서버의 파일 목록(/offline/manifest: 파일마다 내용 해시)을 확인 (15초에 한 번, 3초 안에 안 오면 오프라인으로 봄)
   ├ 저장해 둔 것의 해시가 같음      → 저장해 둔 것을 바로 (내려받지 않음)
   ├ 다르거나 없음                   → 서버에서 받아 저장
   └ 인터넷이 안 됨                  → 저장해 둔 것
```

| 종류 | 방식 |
|---|---|
| 웹 파일 (화면·아바타·라이브러리·출처 이미지·수어 인식 모델) | 해시 비교. 첫 로딩이 끝나면 목록의 파일을 뒤에서 모두 받아 둠 (약 60개) |
| 질문 답 (`POST /query`) | 서버 먼저, 받을 때마다 저장. 오프라인이면 저장해 둔 답. 질문은 띄어쓰기·문장 부호를 빼고 비교 |
| 단어 동작 (`POST /motions`) | 서버 먼저, 단어마다 따로 저장. 오프라인이면 요청한 단어 중 저장해 둔 것만 모아 답함 |
| 예시 질문 목록 등 그 밖의 GET | 서버 먼저, 실패하면 저장해 둔 것 |
| 글꼴 (Google Fonts) | 한 번 받은 것은 저장해 둔 것 |
| SOS (`/sos/`) | 저장하지 않음 (실시간 정보) |

배포로 파일이 바뀌면 해시가 달라져 그 파일만 새로 받는다. 화면 파일과 코드가 섞이지 않도록 서버는 모든 웹 파일에
`Cache-Control: no-cache` 를 붙인다 (바뀌지 않았으면 304).

## 오프라인에서 되는 것 / 안 되는 것

| 기능 | 오프라인 |
|---|---|
| 화면 열기, 아바타 | 됨 (한 번 접속한 기기) |
| 예시 질문, 전에 물어본 질문의 답·수어·출처 | 됨 |
| 처음 하는 질문 | 안 됨 (문서 검색·답 만들기는 서버에서) |
| 카메라 수어 입력 (낱말 인식·질문 찾기) | 됨 (모델이 기기에 저장됨, 영상은 원래 기기 밖으로 나가지 않음) |
| 음성 입력 | 브라우저에 따라 다름 (대부분 인터넷 필요) |
| SOS | 안 됨 (실시간 병상·경로) |

## 확인 방법

- 저장 상태: 브라우저 개발자 도구 → Application → Cache Storage → `ieum-offline-v2`
- 파일 목록: `/offline/manifest`
- 처음부터 다시 받기: Application → Storage → Clear site data
