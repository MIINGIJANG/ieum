# SOS — 통화 없이 가까운 응급실 찾기

청각장애인은 전화로 신고하거나 병원에 물어보기 어렵다. 그래서 응급 상황에 필요한 정보를 **통화 없이 화면으로** 준다.
입력창 옆 SOS 버튼을 누르면 지금 위치에서 차로 가장 빨리 닿는 응급실과 가는 길, 병상, 진료 가능 정보를 보여준다.

- 화면: `web/sos.js` (팝업 틀·움직임은 카메라 수어 입력과 같은 `web/sign/popup.css`)
- 서버: `ksl/sos.py`, 엔드포인트 `/sos/config` · `/sos/nearest` · `/sos/status`
- 키(서버 환경 변수에만 둠): `DATA_GO_KR_KEY`(공공데이터포털), `KAKAO_REST_KEY`(경로·장소), `KAKAO_JS_KEY`(지도 표시용 공개 키)

## 흐름

```
SOS 버튼 → 위치 권한 (허용하는 순간 팝업) → 지금 위치 (누를 때마다 새로)
        → 서버 /sos/nearest?lat&lng&fresh=1
            ├ 가까운 응급의료기관 16곳 (공공데이터 위치 조회)
            ├ 지정 응급의료기관만 남김 (권역·전문·지역응급의료센터, 지역응급의료기관)
            ├ 가까운 6곳: 카카오 장소로 이름·위치 맞춤 → 자동차 경로 (동시에)
            ├ 지역별 실시간 병상 · 진료과별 진료 가능 정보 · 병원이 올린 진료 제한 메시지 (동시에)
            └ 차로 빨리 닿는 순으로 정렬 → 2곳 (둘 다 병상이 없으면 병상 있는 곳이 나올 때까지 더)
        → 지도(현위치·경로·도착) + 응급실 칸
```

## 응급실 고르는 기준

| 항목 | 기준 |
|---|---|
| 대상 | 지정 응급의료기관만. 응급실운영신고기관(정형외과 전문병원 등)은 뺌. 그 지역 등급 정보를 못 받으면 거르지 않음 |
| 순서 | 자동차 이동 시간 → 거리 → 응급실 남은 병상 많은 순 → 직선거리. 경로를 못 구한 곳은 뒤로 |
| 개수 | 기본 2곳. 2곳 모두 병상이 없으면 병상 있는 곳이 나올 때까지 이어서 |
| 등급 | 공공데이터의 값 그대로 (`dutyEmclsName`) |
| 진료 가능 정보 | 공식 27개 항목을 분야 5개로 묶어 **가능 / 제한 / 정보 없음** (값이 안 오면 정보 없음) |
| 진료 제한 메시지 | 병원이 올린 문장 그대로 (최대 3개, 내용 없는 자리표시 문구는 뺌) |

## 개인정보·신뢰

- 위치는 서버에 저장하지 않고 기록에도 남기지 않는다. 오류 기록에서는 주소 뒤 `?…`(키·좌표)를 지운다
- 병상·진료 가능 정보는 실시간 값이라 화면을 열 때마다 새로 조회하고, 오프라인 저장(`web/sw.js`)에서도 뺀다
- 병상 정보는 병원이 입력한 시각을 같이 보여준다 (오래된 값일 수 있음)
- 운영 확인: `/sos/status` (요청 수·성공·단계별 실패·평균 시간·최근 오류, 위치 없음)
