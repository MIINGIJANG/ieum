# 수어 좌표 품질 평가 보고서

## 평가 개요

수어 영상의 좌표 추출 → 짧은 누락 보간 → 어깨 기준 정규화 → 품질 검사 → 구현용 구조 변환을 평가하였다. 자동 평가에는 수동 보정을 적용하지 않았다. 별도로 수동 보정한 자료의 오류 후보 감소와 작업량을 정리하였다.

| 평가 | 자료 | 규모 | 기준 |
|---|---|---:|---|
| 2D 위치 일치도 | AI Hub 샘플 영상 23개에서 추출한 70개 클립 | 2,006클립 프레임·중복 제거 1,949프레임 | 제공 2D 좌표 |
| 상대3D 일치도 | AI Hub 3D 라벨 보유 원본 영상 4개 전체 | 2,549프레임·19개 연속 구간 | 제공 3D 좌표 |
| 수동 보정 | 직접 추출한 별도 수어 영상 13개 | 1,464프레임 | 원영상 검수·중복 라벨 규칙 |

평가 영상의 촬영자는 TW07이며 모두 한파 안내 자료이다. 직접 촬영한 영상은 사용하지 않았다. 추가 35개 클립은 단어 목록과 겹치지 않는 프레임 범위로 선정했으며 예측 점수에 따라 골라내지 않았다.

## 1. 2D 위치 일치도

원본 영상과 제공 라벨의 프레임 범위·FPS·해상도를 확인해 같은 구간을 재구성하였다. 후처리 좌표는 저장된 어깨 중심·너비로 원영상 픽셀 좌표에 역변환하였다. 기준 라벨에 맞추는 위치 정합, 시간 이동, 좌우 최적 교환은 하지 않았다.

기준 confidence 0.5 이상이고 양 어깨 기준이 유효한 양손 66,382점과 상체 12,035점을 평가하였다. PCK@0.1은 기준 어깨너비 10% 이내의 2D 위치 일치율이다. 예측 누락도 같은 분모에 남겨 실패로 계산하였다.

처리 설정은 30fps, 최대 5프레임 선형 보간, 스무딩 OFF, 트리밍 OFF, 가상 휴지 OFF이다.

| 지표 | 추출 직후 | 자동 후처리 | 변화 |
|---|---:|---:|---:|
| 양손 PCK@0.1 | 93.40% | 95.81% | +2.41%p |
| 양손 좌표 존재율 | 95.26% | 99.07% | +3.81%p |
| 미확정·누락 관절 | 3,149점 | 617점 | 80.41% 감소 |
| PCK@0.1 실패 관절 | 4,381점 | 2,784점 | 36.45% 감소 |

보간으로 추가된 2,532점 중 1,597점(63.07%)이 PCK@0.1 범위에 들어왔다. 두 단계에서 공통으로 존재한 점의 평균 정규화 오차는 0.02491 → 0.02491로 사실상 동일하였다. 개선은 주로 짧은 누락 구간 보완에서 발생했다.

AI Hub 계열 구조 변환 후에도 양손 PCK@0.1은 **95.81%**로 동일하였다. 이는 관절 대응·역변환 단계에서 2D 평가 결과가 유지됨을 뜻하며 실측 3D 복원을 의미하지 않는다.

## 2. 3D 상대좌표 비교와 원인 진단

### 비교 조건

3D 라벨이 있는 원본 4개 영상의 2,549프레임 전체를 19개 연속 구간으로 나누었다. 예측을 다시 추론하거나 보정하지 않고 저장된 결과를 고정해 비교·진단하였다. 몸25·손21점 중 공통 상체 6점과 양손 42점을 사용했으며 얼굴은 제외하였다.

제공 `Fprojectionmatrix`의 [K|0] 구조에서 앞면 카메라 축을 해석해 Y·Z를 반전하였다. 정답과 예측은 각각 구간의 어깨 중심·중앙 어깨너비로 정규화했다. 이 축 해석은 보정 행렬에 근거한 것으로, 예측 모델과 제공 라벨의 Z 규약이 동등하다는 독립 검증을 완료한 것은 아니다. 기준 라벨에 맞춘 회전 정합·시간 이동·좌우 최적 교환은 하지 않았다.

단위는 어깨너비이며 mm 또는 m가 아니다. 어깨너비를 임의로 0.4m라 가정한 환산값을 실제 거리 오차로 보고하지 않는다. 절대 위치·실제 크기·카메라까지의 거리를 평가한 수치도 아니다.

제공 3D에 confidence가 없어 유한·비영 좌표와 유효한 어깨를 기준으로 삼았다. 평균 오차는 공통 관절에서, PCK는 미검출도 포함한 고정 분모에서 계산했다. 아래는 **Z 규약 검증 전의 상대좌표 비교 수치**이며 3D 복원 성능의 확정 평가로 해석하지 않는다.

### 원래 예측의 비교 수치

| 지표 | 양손 | 상체 |
|---|---:|---:|
| 기준 관절 | 107,058점 | 15,294점 |
| 예측 좌표 존재율 | 97.72% | 100.00% |
| 평균 3D 거리 | 2.373 | 1.158 |
| 평균 Z 절대오차 | 2.366 | 1.153 |
| PCK3D@0.1 | 1.12% | 10.25% |
| PCK3D@0.2 | 2.86% | 20.92% |
| PCK3D@0.5 | 7.13% | 42.54% |
| PCK3D@1.0 | 14.79% | 59.67% |

0.5·1.0은 허용 범위별 경향을 보기 위해 추가했다. 1.0은 어깨너비 전체를 허용하는 넓은 기준이다. 점수가 낮다는 이유로 0.1을 삭제하거나 넓은 기준을 정확한 3D 동작의 합격 기준으로 삼지 않는다. 실제 허용오차는 사용 목적에 따라 사전에 정해야 한다.

### 부호·상관관계·기준선 진단

모든 대안은 **같은 관절·같은 XY·같은 가용도 마스크**를 사용했다. 축·배율 대안은 원인 점검용이며 실제 예측·전달 파일에는 적용하지 않았다.

| 양손 진단 지표 | 값 |
|---|---:|
| 부호 있는 평균 Z 오차 (예측−정답) | +2.143 |
| 평균 Z 절대오차 | 2.366 |
| 전체 Z Pearson 상관계수 | 0.016 |
| 전체 Z Spearman 순위 상관계수 | 0.412 |
| 구간·관절별 Z Pearson 상관계수 중앙값 | 0.509 |

| 진단용 대안 | 평균 3D 거리 | 용도 |
|---|---:|---|
| 원래 파이프라인 예측 | 2.373 | 변경하지 않은 비교 수치 |
| Z=0 기준선 | 0.936 | 추정 깊이의 기여 확인 |
| Z 부호 반전 | 3.773 | 단순 부호 규약 점검 |
| Z×0.25 | 0.488 | 배율 민감도 점검; 성능값으로 채택하지 않음 |

Z=0 기준선이 원래 예측보다 평균 거리가 작고, 부호만 뒤집으면 더 나빠졌다. 배율 변경에 결과가 크게 달라져 **스케일·좌표 규약 불일치 가능성을 먼저 검증할 근거**가 생겼다. 그러나 평가 데이터에서 본 유리한 배율을 그대로 적용하는 것은 검증이 아니므로 배포하지 않았다. 전체 라벨에 맞춘 affine 회귀도 진단 JSON에만 남겼으며 검증 성능으로 사용하지 않았다.

전체 Pearson이 낮다는 사실만으로 깊이 신호가 무의미하다고 단정하지 않는다. 구간별 상관과 순위 상관은 다르게 나타났고, 라벨의 극단값도 확인되었다.

### 라벨 품질 점검

공통 관절의 정답 Z 범위는 -39.39~127.66 어깨너비였으며, |Z|가 10을 넘는 점은 565점이었다. 정답 Z의 1~99백분위 범위는 -0.19~1.63였다. 이 극단값은 라벨·좌표계 확인 대상이며 전부 오류라고 확정한 것은 아니다.

극단값을 기본 평가에서 임의로 제외하지 않았다. 별도 품질 검수 없이 전체 상관계수나 평균 거리만으로 모델의 한계를 확정하지 않는다.

### 해석

현재 확인된 것은 Z 차이·양의 편향·배율 민감도와 라벨 품질 확인 필요성이다. **단안 모델의 한계, 스케일 규약, 기준 라벨 문제를 아직 완전히 분리하지 못했으므로 3D 복원 성능의 결론은 보류한다.** 좌표 정의와 단위를 확인하고 독립 자료에서 고정 보정 규칙을 검증한 뒤 다시 평가해야 한다.

## 3. 수동 보정의 오류 후보 감소와 작업량

정답 라벨이 없는 별도 13개 영상에서는 원영상과 좌표를 함께 확인해 좌우 혼동·중복 검출·누락·관절 위치를 수정하였다. 한 프레임에 Left·Left 또는 Right·Right가 존재하면 중복 라벨 후보로 정의하고 보정 전후 같은 규칙으로 집계하였다.

| 지표 | 보정 전 | 보정 후 |
|---|---:|---:|
| 전체 프레임 | 1,464 | 1,464 |
| 중복 라벨 후보 프레임 | 94 | 10 |
| 후보 비율 | 6.42% | 0.68% |

후보 수는 **89.4% 감소**하였다. 최종 파일 차이 기준으로 173프레임(11.8%)이 변경되었으며, 라벨 변경 110손 세트, 제외 15손 세트, 수동 추가 14손 세트, 보간 추가 48손 세트, XY 직접 수정 16프레임을 기록하였다. 항목은 겹칠 수 있어 합산하지 않았다.

추가된 62손 세트는 깊이가 없는 2D 자료이므로 이 통계가 3D 적용 완료를 뜻하지는 않는다. 중복 후보 비율은 위치 정확도나 전체 오류 검출률이 아니며, 한 손에 Left·Right가 함께 겹친 예측은 이 규칙만으로 검출하지 못한다.

## 4. 해석과 한계

- 자동 후처리는 짧은 누락을 줄이고 2D 위치 일치도를 개선했다. 좌표 존재율 증가를 모두 정확도 향상으로 해석하지 않았다.
- 3D 비교는 Z 규약·스케일·라벨 품질 진단 단계이다. 2D PCK를 3D 정확도로 제시하거나 현재 수치를 확정 복원 성능으로 해석하지 않는다.
- 수동 보정은 별도 자료의 구조적 오류 후보 감소와 작업 실적이며 자동 평가와 합산하지 않는다.
- 단일 촬영자·한파 안내 영상에 한정된다. 직접 촬영 영상과 다양한 촬영 환경으로의 일반화는 확인하지 않았다.
- AI Hub 제공 라벨 자체를 별도로 검증하지 않았으며 수어 의미·문법·농인 사용자의 이해도는 평가하지 않았다.

## 5. 보고서 수행내용 요약

수어 영상의 좌표 추출부터 보간·정규화·품질 검사·구조 변환까지 이어지는 자동 처리 파이프라인을 구축하고, AI Hub 제공 라벨을 활용하여 평가하였다. 2D 평가를 70개 클립, 2,006클립 프레임으로 확대하여 양손 PCK@0.1이 93.40%에서 95.81%로 2.41%p 상승하고, 누락 관절 수가 3,149점에서 617점으로 감소함을 확인하였다. 3D 라벨이 있는 원본 4개 영상의 2,549프레임도 비교하고 부호·상관관계·Z=0 기준선을 진단하였다. 스케일 민감도와 라벨의 극단값이 확인되어 3D 성능 결론은 보류하고 좌표 규약 검증 과제로 분리하였다. 별도 수동 검수 자료에서는 중복 라벨 후보가 94프레임에서 10프레임으로 감소하였다. 자동 처리 후에도 오류가 남는 구간은 원영상과 비교하여 선택적으로 보정하는 절차를 적용하였다.
