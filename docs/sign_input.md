# 카메라 수어 입력 (시험판, `web/sign/`)

카메라로 수어를 하면 낱말을 알아듣고, 비슷한 질문을 찾아 이음에 묻는 **독립 페이지**다. 본 화면(`web/index.html`)은 건드리지 않았고,
완성도를 확인한 뒤 본 화면에 카메라 버튼으로 붙인다.

- 주소: `/sign/` (예: https://miingi-ieum.hf.space/sign/)
- 인식 모델·특징 변환은 팀원 SignBridge(github.com/BioCode67/signbridge) 것을 그대로 씀

## 흐름

```
카메라 → 관절 점 (MediaPipe Holistic, 기기 안) → 특징 155개 × 32프레임 → 낱말 인식 (ONNX, 기기 안)
     → 같은 낱말이 연속 2번·60% 이상이면 확정 → 후보 5개에서 골라 고치기
     → 문서 말로 바꾸기 (머리 + 보호 → 안전모, 입다 → 착용) → 비슷한 질문 3개 / 낱말로 바로 묻기 → 이음 /query
```

- 영상은 기기 밖으로 나가지 않는다. 서버에는 고른 질문 글자만 간다.
- 손이 보인 프레임이 25% 미만이면 답을 내지 않는다 (손이 없을 때 같은 낱말을 자신 있게 내는 문제, 팀원 기록).

## 파일

| 파일 | 내용 |
|---|---|
| `web/sign/index.html`, `app.js` | 화면과 인식 (특징 변환·확정 규칙은 팀원 `landmarks.ts`·`useRecognizer.ts` 와 같은 값) |
| `web/sign/models/model.onnx`, `meta.json` | 낱말 인식 모델 (13,576개, 검증 정확도 78.2%, 25MB) — 팀원 저장소 `public/models/ksl-iso/` |
| `web/sign/models/holistic_landmarker.task` | 관절 점 모델 (14MB) |
| `web/sign/lib/mediapipe/` | MediaPipe Tasks Vision 0.10.35 (Apache-2.0) |
| `web/sign/lib/ort/` | ONNX Runtime Web 1.27.0 wasm (MIT) |
| `web/sign/domain.json` | 산업안전 단어 533개(말 270개), 수어 → 문서 말, 대체 표현 거꾸로, 질문 후보 49개 — `python scripts/data/build_sign_input_vocab.py` |

처음 한 번 약 60MB 를 받는다 (카메라 켜기를 누를 때만). 한 번 받은 기기는 본 화면의 오프라인 저장(`web/sw.js`)에 같이 들어간다.

## 산업안전 단어만

모델의 13,576개 중 우리 서비스에 나오는 말(동작사전·단어표·대체 표현·예시 질문·모범 답안·평가 질문의 낱말 + 질문할 때 쓰는 말)만 남겨
그 안에서 고르게 한다. 헷갈리는 후보가 줄어 정확도가 오를 것으로 보지만, **실제 수어로 잰 값은 아직 없다** (화면에서 끄고 켜며 비교).

모델에 없는 우리 말: 안전모·안전화·장갑·귀마개·보안경·교체·정화통·작업·착용·소음·교육·세척 등.
→ 있는 낱말 조합(머리 + 보호 → 안전모)이나 비슷한 말(입다 → 착용, 바꾸다 → 교체)로 문서 말을 찾는다.

## 지금까지 확인한 것

| 항목 | 결과 |
|---|---|
| 모델 불러오기 → 카메라 → 관절 점 → 인식 → 질문 → 답변 | 가짜 카메라로 끝까지 동작 (오류 없음, 불러오기 약 16초) |
| 질문 찾기 (인식이 완벽하다고 가정, 예시 질문 10개를 그 낱말로) | 1순위 9개, 3순위 안 10개 |
| **실제 사람의 수어 인식 정확도** | **아직 못 잼** — 팀원이 예시 질문을 직접 수어로 해 보고 재야 함 |

## 남은 일

1. 팀원 몇 명이 예시 질문을 수어로 해 보며 낱말 인식·질문 찾기 정확도 재기 (산업안전 단어만 켜고/끄고)
2. 낱말 끊기 다듬기 (지금은 0.25초마다 최근 48프레임을 보고, 같은 낱말 연속 2번이면 확정)
3. 모델에 없는 산업안전 낱말: 팀원 촬영 + 추가 학습, 또는 지문자 인식
4. 완성도가 나오면 본 화면 입력창에 카메라 버튼
