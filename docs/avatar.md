# 3D 수어 아바타 (`web/avatar.js`)

## 모델

- 기본: **반실사 GLB** `web/models/avatar.glb` — [Microsoft Rocketbox](https://github.com/microsoft/Microsoft-Rocketbox) 건설 작업자 `Construction_Male_07` (**MIT**, 주황 안전모·형광 조끼). 라이선스: `web/models/avatar.LICENSE.md`
- 예전 애니메이션풍 VRM 은 주소 뒤에 `?avatar=vrm` (GLB 를 두 번 못 불러오면 자동으로 VRM). 다른 GLB 는 `?avatar=파일이름`
- 설정 `web/models/avatar.json`: 모델에 안전모가 있어 `hat: false`, 번들거림 없애려고 `roughness: 0.78`, 뼈 이름이 다르면 `bones`
- 변환: `scripts/avatar/rocketbox_to_glb.py --subdivide=1 --drop-islands=40 --smooth-armpits=0.14 --twist-bones=1` (Blender: 몸 세분화, 버클 조각 제거, 겨드랑이 가중치 스무딩, 아래팔 비틀림 뼈)
  → `node scripts/deploy/slim_glb.mjs 원본.glb web/models/avatar.glb 2048` 로 31MB → 5MB (모프 법선·눈동자 모프 제거, 텍스처 WebP 2048)

## 부분별 동작

| 부분 | 하는 일 |
|---|---|
| 뼈 연결 (`web/rig.js`) | CC4·Mixamo·MPFB·Ready Player Me·Rocketbox 뼈 이름을 자동 인식해 VRM 과 같은 정규화 뼈대로. cm 단위·뒤를 보는 모델도 자동 보정 |
| 렌더링 | ACES 톤 매핑 + 실내 환경광 + 3점 조명, 피부는 덜 번들거리게, 옷은 짙게(손이 잘 보이게). 아래쪽은 흐리게 사라짐(`config.frameMargin`) |
| 몸통·쇄골 | 데이터 어깨선으로 척추·가슴을 나눠 돌림, 손을 앞으로 뻗으면 살짝 숙임, 숨쉬기. 손을 어깨 위로 들면 쇄골도 듦 |
| 팔꿈치 | 방향 = 데이터 55% + 기본(아래·바깥·뒤) 45%. 그 둘레 ±40°(8° 간격)에서 비용이 가장 작은 자리를 고름 (아래) |
| 손목 | 손 방향은 데이터 절대 방향과 '데이터 손목 각도를 아바타 아래팔에 붙인 방향'의 중간 (`config.wristFollow` 0.5). 범위: 손바닥 쪽 55°·손등 쪽 45°·좌우 20° (일상 동작 범위, Ryu 외 1991). 손목 비틀림의 일부는 아래팔 비틀림 뼈로 |
| 손가락 | 굽힘은 데이터의 마디 사이 각도로, 관절 범위 제한, 끝마디 연동, 겹치지 않게 벌림 제한. 손가락 시너지(데이터 주성분, Santello 외 1998) 쪽으로 35%, 자주 나오는 손 모양(`web/handshapes.json`) 쪽으로 최대 35%. 손이 잠깐 안 잡히면 0.5초 동안 마지막 손 모양 유지 |
| 낱말 사이 | 서버가 연결 구간을 표시(`tr`) → 앞·뒤 자세의 뼈 회전을 최소 저크 곡선으로 섞음 (관절 좌표를 직선으로 섞으면 팔이 짧아졌다 길어짐) |
| 부드러움 | 뼈마다 따라가는 빠르기(손가락 0.03초 ~ 몸통 0.12초)를 프레임 간 시간으로 계산 → 화면 주사율과 상관없이 같은 속도 |
| 고개 | 데이터 각도 + 낱말·문법 움직임(끄덕·젓기·갸웃)을 스프링으로 |
| 얼굴 (`web/face.js`) | ARKit 52 표정 이름으로 통일. 문법 표정(`nms`)은 1.25배 과장. 낱말의 한국어를 입 모양으로(ㅁ·ㅂ·ㅍ 는 입술 닫힘). 시선·깜빡임 |
| 높이 | 동작마다 손 높이를 재서 화면 가운데 쪽으로 (최대 ±0.15m) |

### 팔꿈치 자리 비용

손목이 덜 꺾이도록 팔꿈치를 고르는 비용 (작을수록 좋음):

```
손목 꺾임 + 0.8 × 손등 쪽 젖힘 + 6 × 팔꿈치가 어깨 가까이 들림 + 5 × 팔꿈치가 옆으로 벌어짐
+ 0.25 × 돌린 각도 + 0.3 × 데이터 위팔과 다른 정도 (SMPLify-X 식 데이터 충실도)
+ 0.5 × 직전 화면과 다른 정도 (최소 토크 변화, Uno·Kawato 1989)
− 0.15 × 손을 입·얼굴 쪽으로 움직이기 쉬운 정도 (조작성 타원, Kim·Rosen 2012)
```

전체 116개 동작에서 잰 결과: 평균 손목 꺾임 28.4° → 22.4°, 상위 10% 41.1° → 33.6°.

## 다른 화면에서 쓰기

`SignAvatar` 클래스를 가져와 `await new SignAvatar(canvas).load(url)` 후 `setFrameAt(motion, 프레임, 낱말정보)` 를 화면 주기마다 부르면 된다 (`web/index.html` 의 `play()` 참고).
