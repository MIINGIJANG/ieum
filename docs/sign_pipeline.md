# 답변을 수어로 — 수어 문장·블록·동작

화면에는 문서 근거로 쓴 자세한 답변을 보여주고, 아바타는 그 답변을 **짧고 완성된 한 문장**으로 줄인 수어 문장을 표현한다.
수어 블록(화면의 단어 상자)만 이어 읽어도 문장이 되도록 하는 것이 원칙이다.

```
답변 ─▶ 수어 문장 고르기 (ksl/keypoints.py extract)
     ─▶ 낱말 → 글로스 (ksl/pipeline.py SignWords, data/sign/sign_words.csv)
     ─▶ 어순·문법 표정 (ksl/order.py)
     ─▶ 숫자·시간 수어, 대체 표현 (ksl/pipeline.py _expand_numbers, _substitute)
     ─▶ 동작 이어붙이기 (ksl/motion.py compose) ─▶ 아바타
```

## 1. 수어 문장 고르기 (`ksl/keypoints.py`)

먼저 맞는 것을 쓴다.

1. **수어용 문장(hint)** — 블록 최대 12개 (`HINT_MAX`)
   - 준비된 질문: 사람이 줄여 쓴 문장 (`data/kosha/answers.json` 의 `sign`)
   - Claude 답변 모드: ① 문서 근거로 답변 (`ksl/rag.py`) → ② 그 답변을 수어 동작이 있는 말 위주의 짧은 한 문장으로 (`llm_sign_sentence`)
     → ③ 규칙 점검 + Claude 검수로 고침 (`llm_review`)
   - 쓰지 않는 경우 (`from_hint`, 이유는 `/blocks.html` 에 표시): 답변에 없는 부정·금지가 들어감, 답변에도 수어 단어 목록에도 없는 말이 있음, 블록이 너무 많음
2. **답변 문장 통째로** — 끝맺음이 있는 정상 문장(괄호·기호 없음) 중 질문에 가장 맞는 것, 블록 최대 16개, 점검을 통과할 때만
3. **규칙 방식** (`rule_based`) — 위가 모두 안 되면 핵심 낱말

`KSL_KEYPOINTS=llm` 이면 2 앞에 Claude 가 핵심 낱말을 고르는 방식(`llm_based`)을 먼저 시도한다 (기본은 `rule`).

### 블록 완결성 점검 (`check_blocks`)
- 마지막 블록이 끝맺음(~다·~요·~니다)으로 끝나는가
- 블록을 이어 읽으면 수어 문장과 같은가 (쉼표는 '그리고' 블록으로 이음)
- 블록이 너무 많지 않은가
- 조건이 '-고'로 이어지지 않았는가 ('위험이 있고' → '위험이 있으면')

예시 질문 전체 점검표: `/blocks.html` (서버 `GET /blocks_check`), CI 평가 요약에도 같은 표가 나온다.

## 2. 낱말 → 글로스 (`SignWords`)

- 형태소 분석(kiwipiepy)으로 명사·동사·형용사·일부 부사를 뽑는다. 보호구 이름 같은 전문 용어는 한 낱말로 등록해 둠.
- `data/sign/sign_words.csv` 에서 말 → 글로스 (예: 착용 → 입다1, 분진 → 먼지1#). `=말` 은 어절 전체가 같을 때만.
- 표에 없으면 낱말 그대로 글로스로 쓰고, 동작사전에서 번호만 다른 글로스(예: 중요 → 중요1)를 찾는다.
- 숫자+단위는 한 낱말로 ('6' + '개월' → '6개월'), 복수 '-들'은 떼어냄 ('방법들' → 방법).
- 화면 블록에는 답변에 쓰인 모양 그대로 보여준다 ('착용해야', '이상이').

## 3. 어순·문법 표정 (`ksl/order.py`)

한국수어도 '주어-목적어-동사' 순서라 낱말 순서는 대부분 그대로 두고, 절마다 아래만 바꾼다.

| 한국어 | 수어 블록 | 표정·고개 |
|---|---|---|
| 착용하지 **않으면** 다칠 **수 있습니다** | 입다 **안하다** / 부상 **가능** | 조건절 눈썹 올림, 부정은 고개 젓기 |
| **반드시** 착용**해야** 한다 | 입다 **꼭 필요** | '꼭'·'필요'에서 끄덕 |
| 정화통은 **6개월마다** 교체 | **6개월** 정화통 바꾸다 | 시간 표현은 절 맨 앞 |
| 벗지 **마세요** | 벗다 **금지** | 고개 젓기 + 단호한 얼굴 |
| 착용하지 **않으면 안 됩니다** | 입다 **필요** | 끄덕 |

- 수어용 문장(1번의 hint)으로 만든 블록은 문장 순서 그대로 둔다 (블록만 읽어도 문장이 되게).
- 문법 표정은 `nms` 로 내려가 아바타가 그 낱말 동안 표정·고개를 한다.
- 말뭉치에서 잰 어순 통계(`data/sign/order_stats.json`, 팀원 SignBridge)는 아직 쓰지 않는 참고 자료.

## 4. 숫자·시간·대체 표현 (`ksl/pipeline.py`)

| 경우 | 처리 | 화면 블록 |
|---|---|---|
| '2미터' | 숫자 수어(한국식 읽기, 342 → 삼·백·사·십·이) + 미터 | 블록 하나 ('2미터') |
| '4시간' | 소요 시간 전용 수어 하나 (`시간:4시간`, 1~12시간·24시간) | 블록 하나 |
| '6개월' | 단위 수어가 없어 그대로 | 회색 블록 |
| 동작 없는 낱말 중 대체 표현이 있는 것 | `data/sign/substitutes.csv` (예: 안전모 → 머리 + 보호) | 원래 낱말 블록 하나 (마우스를 올리면 대체 표현임을 표시) |

- 블록 하나가 여러 동작이면 응답의 `group`(숫자) 또는 `sub_of`(대체 표현)가 같은 값이고, 이어지는 동작은 `words` 가 빈 칸이다.
- 대체 표현을 쓸 때마다 '동작 없는 단어 기록'의 대체 표현 표에 남는다 → 수어 전문가 검수용.

## 5. 동작 이어붙이기 (`ksl/motion.py compose`)

- 낱말 길이 맞추기: 0.6~1.4초 밖이면 서서히 맞춤 (사전 영상에서 자른 긴 낱말, 아주 짧은 낱말)
- 낱말 사이: 손이 멀리 움직이거나 많이 돌수록 길게, 최소 저크 곡선. 연결 프레임에는 `tr` 을 붙여 아바타가 두 자세의 뼈 회전을 섞음
- 낱말 끝 짧은 멈춤(0.07초) + **문장 끝 0.35초, '-면/-고/-때/-서' 절 끝 0.2초 쉼**, 마지막 손 모양 0.4초 유지 (`sign_pauses`)
- 처음·끝: 손을 내린 자세에서 올라오고, 끝나면 천천히 내려감
- 관절 좌표 떨림은 One Euro 필터, 손가락은 각도 공간에서 안정화

## 6. 동작이 없을 때

- 동작 없는 낱말은 회색 블록으로 숨기지 않고 보여준다.
- 지문자(`ksl/fingerspell.py`): 손 모양 검수 전이라 기본 꺼짐 (`KSL_FINGERSPELL=1` 로 켬, 답변마다 최대 `KSL_FS_LIMIT`=3개).
- 동작 없는 낱말 기록: `GET /missing` · `/missing.html` (많이 나온 순서). Hugging Face 데이터셋에 보관되어 Space 를 다시 켜도 이어짐 (`ksl/logsync.py`).
- 동작 추가 우선순위: `docs/reports/missing_words_priority.csv`.
