# 동작 데이터 — 형식과 가져오기

동작사전은 `data/sign/motions/` 에 글로스(수어 낱말) 하나당 JSON 하나로 있고, `index.json` 이 글로스 → 파일 이름을 잇는다 (2026-11 기준 220개: 낱말 193 + 숫자 14 + 소요 시간 13).

## 형식

```jsonc
{"gloss": "위험1", "fps": 30, "source": "어디서 가져왔는지", "frames": [
  {"body": [[x,y,z] × 8], "rh": [[x,y,z] × 21] | null, "lh": [...] | null, "face": [...] | null, "expr": {...}, "head": [...]}
]}
```

- `body` 8점: 코, 목, 오른어깨, 오른팔꿈치, 오른손목, 왼어깨, 왼팔꿈치, 왼손목
- `rh`/`lh`: 수어자 본인 기준 오른손/왼손 21점 (0 손목, 1–4 엄지, 5–8 검지, 9–12 중지, 13–16 약지, 17–20 소지)
- 좌표: 목 = (0,0,0), 어깨너비 = 1, x 오른쪽 +, **y 아래 +**, z 카메라에서 멀어지는 쪽 + (`normalize`)
- 안 보인 점·손은 `null`. 2D 자료는 기존 3D 동작의 뼈 길이로 깊이를 추정해 3D 로 저장 (`lift_2d`, source 에 `2D→3D`). 깊이 추정을 안 한 2D 는 쓰지 않음
- 같은 글로스는 문장이 달라도 같은 동작을 다시 씀 → 동작사전에 있는 글로스끼리는 새 문장도 이어붙일 수 있음

## 가져오기 스크립트 (`scripts/data/`)

| 스크립트 | 자료 | 처리 |
|---|---|---|
| `import_team_keypoints.py` | 조원 '문장별_수어키포인트' | 안내 문장 동작 + 조원이 확정한 글로스(번역 메모리) |
| `import_aihub_clips.py` | AI Hub 형태소 JSON 에서 잘라 낸 낱말 구간 | 후보 중 3D·손이 잘 잡힌 것 1개, 2D 면 깊이 추정 |
| `import_mediapipe_json.py` | 팀원 MediaPipe 후처리 좌표 (한국수어사전 영상 등) | 깊이 배율을 뼈 길이로 맞춤 |
| `import_team_3d.py` | 팀원 3D 처리본 (`처리현황.csv` 또는 `자료목록.json` 형식) | 재생 상태(관측 안 된 점·쉬는 손·얼굴 프레임) 적용, y·z 뒤집기, 앞뒤 쉬는 구간·손 올리기 자르기, 8프레임 미만 조각 제외 |
| `import_signbridge.py` | 팀원 SignBridge 저장소의 낱말 동작 사전 (2D) | 고른 낱말·숫자(`수:0`~`수:9`, 십·백·천·만)·소요 시간(`시간:N시간`)만, 2D→3D |
| `build_motion_dict.py` | AI Hub 키포인트 + 글로스 시간 | 같은 글로스 클립 중 길이가 중앙값에 가까운 것 |
| `extract_keypoints.py` | 영상 (MediaPipe) | `pip install mediapipe opencv-python` 필요 |

모든 가져오기는 **이미 있는 글로스(번호만 다른 것 포함)와 검수에서 뺀 글로스는 건드리지 않는다.**

## 빼 둔 동작

| 어디 | 무엇 | 이유 |
|---|---|---|
| `ksl/motion.py` `REMOVED` | 물건1, 때2, 발0 | 동작이 너무 부자연스러움 → 회색 블록 |
| `import_team_3d.py` `SKIP` | 문서·동안·안전모·근로자 등, 2026-11-05 전달본의 다리·모두·밀폐·보다 등 | 손이 머리 위로 가거나 손목이 크게 꺾임, 뜻 확인 필요(동음이의·지명 출처) — 이유는 파일에 |
| `import_signbridge.py` `SKIP` | 물체·평가·환자·렌즈·얼굴·탱크 등 | 2D 깊이 추정 후 손이 머리 위로 감 |

새 자료를 가져온 뒤에는 아바타로 하나씩 재생해 보고 이상한 것은 `SKIP` 에 이유와 함께 넣는다.
팀원 교체 자료(다른 문장에서 잘라 온 구간)는 **뜻 검수가 끝난 것이 아니다.**

## 정리 단계 (재생할 때, `ksl/motion.py compose`)

손 방향 뒤집힘 고치기 → 튀는 점 제거 → 손 회전 부드럽게 → 손가락 각도 안정화 → One Euro 필터 → 낮은 손 힘 빼기.
낱말마다 결과가 늘 같아서 한 번 정리한 것은 저장해 두고 다시 쓴다 (`_clean_clip`). 서버는 켜진 뒤 예시 질문 답을 만들고 나서 모든 낱말을 뒤에서 미리 정리한다.
(질문 하나 처리 시간 중앙값 0.95초 → 처음 0.17초 · 다시 0.04초, 2026-11 측정)
이어붙이기·쉼은 `docs/sign_pipeline.md` 5절.

## 손 모양 (`web/handshapes.json`)

`python scripts/data/build_handshapes.py` — 동작 데이터의 손 모양 군집과 손가락 시너지(주성분 9개, 분산 91%). 동작 데이터가 바뀌면 다시 만든다.
